## 📖 About

This is a single-page, animated portfolio built to showcase my journey into cybersecurity — covering threat detection & triage, incident response, threat intelligence, and SIEM / detection engineering. It includes a live-style scrolling alert ticker, an interactive particle background, scroll-reveal animations, a certifications grid, and a tools & platforms showcase.

Currently pursuing my undergraduate degree (2024–2027) at Jamal Mohamed College, Trichy, with hands-on practice in web application penetration testing, cryptography, digital forensics, and network security through CTFs and lab environments like TryHackMe, Hack The Box, and PicoCTF.

## ✨ Features

- **Animated hero section** with an interactive HTML5 Canvas particle field that responds to cursor movement
- **Live alert ticker** — an infinitely scrolling SOC-style feed of sample security events (severity-tagged: CRIT / HIGH / MED / LOW)
- **Scroll-reveal animations** using `IntersectionObserver` for smooth section transitions
- **Competency showcase** covering triage, incident response, threat intel, and SIEM engineering
- **Certifications grid** with hover interactions
- **Tools & platforms** display (Kali Linux, Splunk, Wazuh, Burp Suite, Wireshark, Nmap, Metasploit, and more)
- **Fully responsive** layout with a mobile-friendly navigation breakpoint
- **Accessible** focus states and reduced-motion support (`prefers-reduced-motion`)

## 🛠️ Tech Stack

- **HTML5** — semantic structure
- **CSS3** — custom properties, grid/flexbox layouts, keyframe animations
- **Vanilla JavaScript** — Canvas API, IntersectionObserver, DOM interactions
- **Google Fonts** — Google Sans Flex, Google Sans Code, Google Symbols

No frameworks, no build step — just open `index.html` in a browser.
